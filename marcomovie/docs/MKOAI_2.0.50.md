# MKOAI 2.0.50

從使用者提供的 2.0.49 完整來源包製作；Maoki 維持暫停。手機／平板版與 TV 版均為 2.0.50，versionCode 20051，package `app.mkoai.player`。請下載對應 APK 手動覆蓋安裝，保留原資料。

## 主要改動

- 重新設計觀看紀錄按鈕：清楚的歷史時鐘圖示、48dp 點擊區、無障礙標籤與長按提示。
- 封面：處理有網址但下載失敗、損壞快取及解碼失敗；搜尋沒有封面時讀同作品詳情，再使用既有 TMDB／豆瓣備援。失敗狀態 60 秒後可重試。首頁、輪播、搜尋、完整清單及繼續觀看共用備援。若供應方確實沒有正確圖片，會保留片名與「暫無封面」提示。
- 清空觀看歷史：立即清本機、保存離線待清空狀態、同步清除目前帳號的雲端舊代次；雲端清除標記單獨讀取，避免超過 200 筆紀錄後漏讀。新代次防止舊版時區錯誤及較晚抵達的舊上傳使紀錄復活。收藏及帳號設定不受影響。
- 主頁只放目前可用設定片源確認收錄的作品；移除全部失敗時回填未驗證推薦的舊回退。來源清單變動會使保留畫面失效。
- Netflix：提供 TMDB Netflix 候選清單，仍先經片源比對；分類下載四個並行、整批等待上限 12 秒、快取並行合併與原子寫入。加入兒童中文／英語資料篩選；TMDB 高分清單使用「高分佳作」標題。
- 系統返回離開搜尋頁會清空關鍵字、取消搜尋並重設篩選與捲動位置。
- 首頁：大幅漸層海報、置中片名與年份／評分、最多三行簡介、清楚播放按鈕、最多五張推薦輪播與指示點；觸摸、離開畫面及無障礙操作時妥善停止輪播。
- 繼續觀看改橫式卡片；分類列分影格建立。播放器補上橫向底列播放／暫停與全螢幕、加強上下漸層對比及圖示語意標籤。

## 驗證

- 本版相關回歸共 **105 項通過**：主頁與封面 22、歷史清除 19、並行與快取 22、搜尋與拼音 34、收藏 8。
- JDK 17 完整編譯及手機／TV APK 打包通過。上游 Kotlin annotation 缺少的既有編譯 warning 仍存在，沒有編譯錯誤。
- 兩個 APK 經 aapt2 核對 package、versionName、versionCode；apksigner 驗證通過；與 2.0.49 手機、TV 原 APK 的憑證一致；zipalign 驗證通過。
- VM 網路實測：awwrated 網頁回傳 403；TMDB Netflix 候選 API 回傳 HTTP 200、20 筆結果。這是候選清單可用性測試。
- 尚未連接使用者手機／TV，未測得真機影格率、實際播放與實際帳號雲端刪除；不宣稱《艾倫的宇宙》已在使用者手機顯示正確封面。

## 裝機驗收

1. 覆蓋安裝後，觀看紀錄按鈕應清楚且容易按。
2. 讓《艾倫的宇宙》及其他缺圖卡片載入，進出詳情與回首頁；有正確可用圖片時應補上，確實無圖時顯示片名提示。
3. 同一帳號手機與 TV 都更新後，清空歷史再同步、重開；舊紀錄不應回來。離線清空後恢復網路也測一次，再播放新作品確認新進度可正常同步。
4. 搜尋輸入文字後按系統返回；再次開搜尋應是空欄位。
5. 停用／移除片源後回主頁，不應顯示只由該源確認的推薦。第三方候選清單不直接充當可播放片源。
6. 捲動分類、滑動推薦輪播、操作橫向播放器，確認 POCO F5 實際順暢度。

## 來源包與重建方式

Drive 上傳工具單檔上限 100MiB，因此分開提供：

1. `mkoai-2.0.50-Source.zip`：程式碼、簽名金鑰、Node 執行庫壓縮封裝、測試與說明。
2. `mkoai-2.0.50-Java-Dependencies.zip`：已核對 SHA-256 的 Maven／AAR 依賴快取。
3. `mkoai-2.0.50-Android-Platform.zip`：Android 35 的平台快取。

將三個 ZIP 解壓到**同一個資料夾**，應形成 `README-BACKUP.txt`、`mkoai-marco.p12` 與 `marcomovie/`；兩個依賴包會補進 `marcomovie/tools/`。Node 原先已解壓的重複二進位檔不重複放入，建置腳本會從主來源包保留的固定版本 Node ZIP 自動還原。程式碼沒有刪減。

若已有 SDK／網路，也可只下載主來源包：建置腳本會下載並檢查固定雜湊的 Java 依賴；Android 平台可使用自己 SDK 的 `android-35/android.jar`。JDK 17、Android build-tools 35、NDK 28.2.13676358 仍須在建置電腦安裝，與原始來源包需求相同。
